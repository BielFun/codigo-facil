ETAPA 2

Crie seu site no GitHub

Agora que você tem o arquivo index.html, publique-o com o GitHub Pages. Para um site estático simples, você não precisa contratar hospedagem.

Crie seu site aqui ↗

Passo a passo para publicar

  1. Acesse o GitHub e entre na sua conta ou crie uma conta seguindo as regras de idade e cadastro da plataforma.
  2. Crie um repositório novo (New repository) com um nome, por exemplo meu-curso-html.
  3. Para começar, deixe o repositório público. Lembre-se de que arquivos públicos podem ser vistos e copiados por outras pessoas.
  4. Dentro do repositório, escolha Add file e depois Upload files para enviar o arquivo index.html.
  5. Confirme o envio com Commit changes.
  6. Abra Settings e entre em Pages.
  7. Na área de publicação, selecione a branch main e a pasta /(root), depois salve.
  8. Aguarde alguns minutos e abra o endereço que o GitHub Pages mostrar. Teste o site no celular e no computador.
Atenção: um site público do GitHub Pages não é uma área privada para compradores. Não coloque senhas, dados pessoais ou informações de pagamento no HTML. Para vender acesso restrito, você precisará de uma solução apropriada para isso.
ETAPA 3

Organize o conteúdo do seu curso

Antes de tentar vender, confira se o curso realmente ensina algo útil. Uma página bonita ajuda, mas o principal é o conteúdo.

  1. Apresentação: explique para quem é o curso e o que a pessoa aprenderá.
  2. Aulas: separe o conteúdo em módulos curtos, do básico ao avançado.
  3. Exemplos: mostre passos claros e exemplos que o aluno possa acompanhar.
  4. Resumo: finalize com uma recapitulação e próximos passos.
  5. Revisão: corrija erros e confira todos os links antes de divulgar.

Modelo de uma aula em HTML

<section class="module">
  <h2>Título da aula</h2>
  <p>Explique aqui o que o aluno vai aprender.</p>
  <ol>
    <li>Primeiro passo</li>
    <li>Segundo passo</li>
  </ol>
</section>

Você pode repetir essa estrutura para criar mais aulas e adaptar as cores e os estilos ao tema do curso.

ETAPA 4

Prepare o curso para vender

Você pode ensinar outras pessoas a criar seus próprios cursos e sites. Deixe claro o que o comprador recebe e não prometa que ele vai ficar rico rapidamente.

Antes de anunciar

  • Escolha um nome claro e um público específico.
  • Liste todos os módulos e explique o formato de entrega.
  • Defina um preço e informe as condições da compra de forma transparente.
  • Use uma plataforma de pagamento confiável e confira as taxas e regras.
  • Respeite direitos autorais, regras de consumo e obrigações fiscais aplicáveis.
  • Se for menor de idade, confira as exigências da plataforma e peça ajuda a um responsável.
Exemplo de descrição honesta: “Aprenda a criar uma página HTML e publicá-la no GitHub Pages. Curso introdutório em texto, com instruções para iniciantes. A prática e os resultados variam; não há promessa de renda.”
ETAPA 5

Ensine o aluno a criar o próprio curso

O aluno que comprar seu curso pode usar o que aprendeu para escolher um tema, criar aulas originais, montar uma página HTML e divulgar seu produto. Ele não deve precisar recrutar pessoas para que você ganhe dinheiro; a proposta é vender conhecimento útil.

Um caminho responsável

  1. Escolher um assunto que conheça ou pesquisar para ensiná-lo corretamente.
  2. Produzir conteúdo original e revisar as informações.
  3. Publicar uma amostra e pedir opiniões.
  4. Divulgar sem spam, depoimentos inventados ou promessas de ganhos garantidos.
  5. Calcular custos, taxas e receitas para avaliar se as vendas dão lucro.
Importante: não existe método garantido para ficar rico rapidamente. Vender cursos pode gerar renda, mas também pode não gerar vendas. Seja transparente sobre isso.

A ordem do seu projeto

  4. Preparar uma oferta clara e uma forma adequada de pagamento.
